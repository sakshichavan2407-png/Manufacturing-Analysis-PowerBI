# Manufacturing Analysis Dashboard | Power BI

## Overview
An interactive Power BI dashboard that analyzes manufacturing operations,
covering production output, efficiency, wastage, rejections, and delivery
performance. The report has two pages: Production Overview and Operation &
Quality.

## Key Metrics
- Total Manufactured Quantity
- Total Processed Quantity
- Efficiency %
- Wastage %
- Total Rejected Quantity
- Rejection % by Machine
- Work Orders
- Late Delivery %

## Dashboard Pages

**1. Production Overview**
- KPI cards for manufactured quantity, efficiency, wastage, and rejections
- Monthly production trend
- Rejected quantity by operation
- Total order value by buyer
- Work orders by delivery period

**2. Operation & Quality**
- Wastage % by department
- Rejection % by machine
- Work orders by buyer and delivery period
- Monthly processed quantity vs wastage %

## Filters
Date, Buyer, Department, and Delivery Period slicers on both pages.

## Tools Used
- Power BI Desktop
- DAX
- Power Query
- Data Modeling

## How to Use
1. Download `Manufacturing_analysis_project.pbix`
2. Open it in Power BI Desktop
3. Use the slicers to explore the data
